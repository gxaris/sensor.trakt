# Trakt PKCE development branch

This branch is an experimental PKCE update to the upstream Trakt Home Assistant custom integration.

## Changes
- Uses Home Assistant's `LocalOAuth2ImplementationWithPkce` for authorization-code S256 PKCE.
- Makes the Trakt client secret optional during setup.
- Preserves existing sensor/coordinator behavior.
- Checks OAuth token validity before calendar updates and synchronizes refreshed tokens into pytrakt.

## Setup
1. In Trakt's application settings, set the redirect URI to the exact URI generated by Home Assistant. Depending on Home Assistant setup this can be `https://my.home-assistant.io/redirect/oauth` or your HTTPS Home Assistant base URL plus `/auth/external/callback`.
2. Install this repository as a custom HACS integration (category: Integration) and select this development branch if HACS supports it; alternatively copy `custom_components/trakt` into your Home Assistant configuration directory.
3. Restart Home Assistant.
4. Add the Trakt integration and enter the application's client ID; leave the secret blank for PKCE.

**Validation:** Home Assistant Core 2026.9.4 user-confirmed PKCE login, populated calendar sensor, poster artwork and successful forced token refresh. Automatic expiry-triggered refresh remains unverified. Existing installations should be backed up before testing. Do not remove your existing integration until connectivity has been proven.
